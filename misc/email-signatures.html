Where to paste

  1. Gmail: Settings, See all settings, General, Signature, Create new. Paste, then press Save Changes at the bottom of the page.
  2. Apple Mail: Mail, Settings, Signatures. Add a signature to the account, paste, and untick "Always match my default message font".
  3. Anything that takes raw HTML: use Copy HTML source.

The banner

Copied signatures load the banner from docs.jumperless.org/assets/jumperless-signature.png, which is docs/assets/jumperless-signature.png in the Jumperless-docs repo. Moving or deleting that file breaks the image in every email already sent. The previews on this page use the copy next to this page instead.
