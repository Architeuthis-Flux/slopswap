Publishing on slopswap

slopswap.org is a plain static site for documents Claude makes for Kevin, hosted where claude.ai is blocked. Every file on it is public. There is no build step to remember: drop an HTML file in a project folder, push, and it is live at slopswap.org/<project>/<file>.html about a minute later.

Where things go

FolderWhat lives thereTheme
misc/One-off documents that belong to no projectJumperless
del-mar-plate-freezer/Del Mar Seafoods vertical plate freezer projectDel Mar
<new-project>/Any new folder becomes a project and gets its own index pageJumperless unless the page says otherwise

Add a document

  1. Save the page as <project>/<name>.html. Pages always live exactly one folder deep.
  2. Link a theme near the top of the file with a relative path: 
    <link rel="stylesheet" href="../styles/jumperless.css">
<link rel="stylesheet" href="../styles/delmar.css">
  3. Commit and push. The pages workflow rebuilds the index pages and deploys.
Moving thingsFolders are the only organisation. Move a file between folders in Finder, push, and its URL and its listing follow. The page keeps whichever theme it links.

What a theme gives a page

Both stylesheets define the same tokens, so a page's own styles work under either one: --bg, --surface, --fg, --muted, --line, --accent, --accent-2, --font-display, --font-body, --font-mono. Headings, tables, code, .callout, .pill, .eyebrow and dl.meta are styled. Jumperless adds the ten wordmark colors as --r1 to --r10 and a --rainbow gradient; sibling h2 markers walk the rainbow in order, like the docs sidebar.

Rules that keep pages loading in China

  • No Google Fonts. Lato, Roboto Slab, Unica One and Overpass are self-hosted in styles/fonts/.
  • No CDN scripts or stylesheets. cdnjs usually gets through, nothing else does; inline the page's own JS.
  • Images sit next to the page in its folder.
  • Chinese text uses the reader's system CJK font. Nothing to ship, and it matches what they see everywhere else.

Preview locally

python3 build.py && python3 -m http.server -d _site 8000

Double-clicking a page in Finder also works, since every link is relative.

Hosting

The repo is ~/Documents/GitHub/slopswap. GitHub Pages serves the _site/ folder the workflow builds. Cloudflare holds the DNS with the proxy on and SSL set to Full, which hides GitHub's addresses behind Cloudflare's, the more reliably reachable of the two from China.
